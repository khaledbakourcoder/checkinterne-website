# Checkinterne GmbH – Website (Variante 2 „Baustellen-Album“)

Statische Seite ohne Build-Schritt: `index.html`, `style.css`, `main.js`, Bilder in `img/`.

Lokal ansehen: `python -m http.server` und http://localhost:8000 öffnen.

Deployment (z. B. Vercel): Framework „Other“, kein Build-Befehl, Ausgabeverzeichnis = Projektwurzel.
